# Changelog — Search SHARE

## 1.1.0 — 2026-10-19

- Renamed extension, context-menu label, and repository folder to **Search SHARE**.
- Added an options page styled like Read Selection Aloud's settings.
- Added configurable SHARE member library subdomain in `chrome.storage.local`.
- Validates a single hostname label, normalizes case, previews the destination, and supports reset to `carp`.
- Added SHARE system explanation and step-by-step official Library Locator instructions.
- Preserved original selection keyword URL, parameter order, and encoding.
- Added toolbar access to settings, automated tests, and developer/test documentation.
- Removed redundant web-accessible icon exposure, retaining the original unbranded book icons.
- Renamed current directory `search-carpl/` → `search-share/`; v1.0 files remain in Git history.

## 1.0 — initial source publication

- Published the original fixed-destination context-menu extension from the uploaded archive.
- Added installation, privacy, troubleshooting, and development documentation.
