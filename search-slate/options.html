Search Slate

Choose your Slate hostname and toolbar icon.

Slate destination

Enter only the hostname, such as admission.ic.edu. Do not include https://, a port, a path, or a query string. Searches always use HTTPS.

The original Slate lookup path and lookup-base ID are preserved; this setting changes only the hostname.

Use a trusted Slate hostname. Your selected search text will be directed to the site you configure.

Toolbar icon pack

Choose four separate PNG images at once—exactly 16×16, 32×32, 48×48, and 128×128 pixels. Each must be square and no larger than 256 KB. Transparent backgrounds are recommended.

Filenames can vary; images are matched by their pixel dimensions. All four sizes are required. Icons stay on this Chrome installation.
