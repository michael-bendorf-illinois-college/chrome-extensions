# Changelog

## 1.1.0 — Configurable hostname and toolbar icons (2026-10-19)

- Added a settings page inspired by the Read Selection Aloud extension.
- Added hostname customization with HTTPS-only search URL construction and validation.
- Preserved the original Slate lookup route, query parameters, fixed lookup-base ID, and search-state behavior.
- Added upload and preview of four PNG toolbar icons (16×16, 32×32, 48×48, 128×128), with format, dimensions, and file-size validation.
- Added local preference persistence, startup icon restoration, original-icon reset, and rollback when icon application fails.
- Added a dedicated icon-pack preparation guide and expanded installation/developer documentation.
- Left the four bundled source PNG images unchanged.

## 1.0 — Initial GitHub publication (2026-10-19)

- Published the supplied `search_slate.zip` application source (Chrome extension version `1.0`), including four PNG icons, without source-code changes.
- Added an extension README with installation, usage, permissions, institutional configuration, privacy, and troubleshooting guidance.
- Added detailed implementation notes and a repeatable manual test checklist.
- Documented the hardcoded Illinois College Admission Slate URL, lookup-base dependency, and initial static validation.

No earlier release history was supplied with the original archive.
